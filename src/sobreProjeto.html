PROJETO IOT

Sistema de Monitoramento com IoT

O projeto consiste em um sistema capaz de monitorar em tempo real condições ambientais por meio de sensores de temperatura, umidade e gases. Os dados coletados são enviados para uma plataforma web, permitindo que os usuários acompanhem as informações de forma prática e visual através de gráficos, indicadores e alertas.

Metas

Objetivos

  • ✓ Monitorar temperatura, umidade e qualidade do ar.
  • ✓ Coletar e processar dados em tempo real.
  • ✓ Exibir informações em uma interface web intuitiva.
  • ✓ Armazenar histórico para consultas futuras.
  • ✓ Gerar alertas imediatos quando valores críticos forem detectados.

Comunicação

Protocolo MQTT & Broker Mosquitto

O MQTT (Message Queuing Telemetry Transport) é um protocolo leve projetado para IoT, baseado no modelo de Publicação e Assinatura (Publish/Subscribe).

01

Publicação

Os sensores coletam dados e enviam informações para tópicos específicos no broker.

02

Intermediação

O Mosquitto organiza e gerencia a fila de mensagens distribuindo aos clientes.

03

Assinatura

Os clientes conectados recebem os dados instantaneamente sem precisar requisitar a cada instante.

Como o broker Mosquitto atua no sistema:

Passo 1

Recebe os dados brutos enviados pelos sensores em tempo real.

Passo 2

Organiza e categoriza as mensagens em tópicos estruturados.

Passo 3

Distribui as informações automaticamente para os clientes conectados.
